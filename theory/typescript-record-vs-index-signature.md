# TypeScript: Record<K, V> vs Index Signature

При работе со словарями (объектами-маппингами) в TypeScript часто встает выбор между двумя способами типизации: использованием Utility Type `Record<K, V>` и классической сигнатурой индекса (Index Signature).

## 1. Record<K, V> (Рекомендуемый подход)

`Record` — это встроенный вспомогательный тип, который делает код более декларативным и читаемым.

```typescript
const map: Record<string, string> = {
    '(': ')',
    '[': ']',
    '{': '}'
};
```

### Преимущества:
- **Читаемость:** Сразу понятно, что объект используется как словарь.
- **Краткость:** Меньше синтаксического шума по сравнению с `[key: string]`.
- **Легкое ограничение ключей:** Если ключи — это конкретный набор строк (Union), `Record` справляется идеально:
  ```typescript
  type Bracket = '(' | '[' | '{';
  const map: Record<Bracket, string> = { ... };
  ```

---

## 2. Index Signature (Классический подход)

Синтаксис, который существовал в TypeScript с ранних версий.

```typescript
const map: { [key: string]: string } = {
    '(': ')',
    '[': ']',
    '{': '}'
};
```

### Когда использовать:
- Когда вам нужно определить объект, в котором **помимо** динамических ключей есть и фиксированные свойства:
  ```typescript
  interface MyConfig {
      version: number;          // Фиксированное свойство
      [key: string]: any;       // Динамические ключи
  }
  ```

---

## 3. Best Practice: Использование `as const`

Для константных маппингов (как в задаче со скобками) часто лучшим решением является не явная типизация через `Record`, а использование литеральных типов через `as const`.

```typescript
const bracketPairs = {
    ')': '(',
    '}': '{',
    ']': '['
} as const;

// TypeScript теперь точно знает, что:
// bracketPairs[')'] имеет тип '(' (а не просто string)
```

Это обеспечивает максимальную типобезопасность в алгоритмах, так как исключает возможность попадания неожиданных значений.

## Итог

1. Используйте **`Record<K, V>`** для большинства случаев, когда вам нужен словарь. Это современный стандарт.
2. Используйте **Index Signature**, если вам нужно смешивать динамические ключи с обычными свойствами в одном интерфейсе.
3. Используйте **`as const`** для неизменяемых справочников, чтобы получить максимально точные типы.
