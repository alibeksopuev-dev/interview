# Разбор функции cleanBody и Big O

---

## Что делает cleanBody?

`cleanBody` — утилита для очистки тела HTTP-запроса перед отправкой на сервер.

Она принимает объект и возвращает новый объект без «мусорных» значений:

| Значение поля    | Действие                        |
| ---------------- | ------------------------------- |
| `''` (пустая строка) | **Удалить** поле            |
| `[]` (пустой массив) | **Удалить** поле            |
| `number`         | **Преобразовать** в `string`    |
| Всё остальное    | **Оставить** без изменений      |

**Зачем это нужно?** Многие API-ы не принимают пустые строки и пустые массивы — они трактуются как «сбросить значение» или вызывают ошибку валидации. Числа превращают в строки, чтобы они корректно сериализовались в `FormData` или `query string`.

---

## Пример

```ts
const input = {
  name: 'Alice',
  age: 30,
  email: '',
  tags: [],
  tags2: ['js', 'ts'],
  score: 0,
}

cleanBody(input)
// =>
// {
//   name: 'Alice',
//   age: '30',       // число → строка
//   tags2: ['js', 'ts'],
//   score: '0',      // 0 тоже число → строка
// }
// email и tags удалены
```

## Пошаговый разбор функции

```ts
const cleanBody = (data: Record<string, unknown>): Record<string, unknown> =>
  Object.fromEntries(
    Object.entries(data)
      .filter(([, v]) => v !== '' && !(Array.isArray(v) && v.length === 0))
      .map(([k, v]) => [k, typeof v === 'number' ? String(v) : v]),
  )
```

### Шаг 1 — `Object.entries(data)`

Превращает объект в массив пар `[key, value]`:

```ts
{ name: 'Alice', age: 30, email: '' }
// =>
[['name', 'Alice'], ['age', 30], ['email', '']]
```

### Шаг 2 — `.filter(([, v]) => ...)`

`[, v]` — деструктуризация с пропуском ключа (запятая без имени слева). Фильтруем, оставляя только те пары, где значение **не** является пустой строкой и **не** является пустым массивом:

```ts
.filter(([, v]) => v !== '' && !(Array.isArray(v) && v.length === 0))
```

Разбор условия:

| Проверка | Что делает |
|---|---|
| `v !== ''` | Убирает пустые строки |
| `Array.isArray(v)` | Проверяет, что это массив |
| `v.length === 0` | Проверяет, что массив пустой |
| `!(... && ...)` | Убирает пустые массивы |

Оба условия через `&&` — поле удаляется, только если оно **и** массив, **и** пустой.

### Шаг 3 — `.map(([k, v]) => ...)`

Преобразуем значения: если `v` — число, конвертируем в строку через `String(v)`. Иначе оставляем как есть:

```ts
.map(([k, v]) => [k, typeof v === 'number' ? String(v) : v])
```

### Шаг 4 — `Object.fromEntries(...)`

Превращает массив пар обратно в объект:

```ts
[['name', 'Alice'], ['age', '30']]
// =>
{ name: 'Alice', age: '30' }
```

## Big O анализ

Пусть `n` — количество полей в объекте `data`.

### Временная сложность — O(n)

| Операция | Сложность | Почему |
|---|---|---|
| `Object.entries(data)` | O(n) | Перебирает все поля |
| `.filter(...)` | O(n) | Один проход по всем парам |
| `.map(...)` | O(n) | Один проход по отфильтрованным парам |
| `Object.fromEntries(...)` | O(n) | Собирает новый объект из пар |

Итого: **O(n)** — линейная сложность.

Все операции выполняются последовательно (не вложенно), поэтому сложности суммируются, а не перемножаются: O(n) + O(n) + O(n) = **O(n)**.

### Пространственная сложность — O(n)

- `Object.entries` создаёт массив из `n` пар — **O(n)**
- `.filter` создаёт новый массив до `n` пар — **O(n)**
- `.map` создаёт новый массив до `n` пар — **O(n)**
- `Object.fromEntries` создаёт новый объект до `n` полей — **O(n)**

Итого: **O(n)** — три промежуточных массива, каждый размером не более `n`.

> Реализация через `reduce` (V3 в .ts файле) тоже O(n) по времени, но использует **один** промежуточный объект вместо трёх массивов — меньше давления на GC при больших объектах.

## Ключевые концепции

| Концепция | Роль в cleanBody |
|---|---|
| `Object.entries` / `Object.fromEntries` | Конвертация между объектом и массивом пар |
| Деструктуризация `[, v]` | Пропускаем ключ — нужно только значение для фильтрации |
| `Array.isArray(v)` | Единственный надёжный способ проверить массив (typeof даёт 'object') |
| `typeof v === 'number'` | Проверяет примитивный тип. Работает для `0`, `-1`, `NaN`, `Infinity` |
| `String(v)` | Безопасное преобразование числа в строку (`String(0)` → `'0'`, не пустая строка) |
| Цепочка методов | filter + map = один логический проход с двумя независимыми шагами |

---

## Граничные случаи

```ts
cleanBody({ x: 0 })       // { x: '0' }  — 0 это число, не falsy-фильтр
cleanBody({ x: false })   // { x: false } — boolean не трогаем
cleanBody({ x: null })    // { x: null }  — null не трогаем
cleanBody({ x: [] })      // {}           — пустой массив удаляется
cleanBody({ x: [''] })    // { x: [''] } — массив с пустой строкой НЕ удаляется (не пустой)
cleanBody({ x: '' })      // {}           — пустая строка удаляется
cleanBody({ x: ' ' })     // { x: ' ' }  — пробел это не пустая строка!
```

## Сравнение реализаций

| Реализация | Читаемость | Промежуточные структуры | Подходит для |
|---|---|---|---|
| `entries + filter + map + fromEntries` | Высокая | 3 массива | Интервью, читаемый код |
| Явные переменные (V2) | Очень высокая | 3 массива | Объяснение коллегам |
| `reduce` (V3) | Средняя | 1 объект | Оптимизация по памяти |
